FieldKit Reborn 0.1.0-reborn.15 — native materials and independent cards

Unthemed cards and settings now assemble the installed native metal frame at its intended 32-pixel edge size and native outer padding. Backdrops stay at the content frame level so labels are not occluded. Buttons use preserved end caps from the native nameplate material; missing native UI assets fall back to the stock tooltip border.

Meter tabs use a single-line native text treatment with a selected underline. Reset has its own wide button above the meter. Original tab handlers, including right-click detach, are forwarded and restored when a theme owns the HUD. Headers have separate space above rows. Linked-card opt-in remains available, with gaps that include the new outer metal.

Independent unthemed cards avoid each other and visible native minimap/target/player-health regions. Automatic movement does not overwrite saved anchors. User overlap/group choices remain respected. Boss progression can use the native charge-bar builder when available, with the existing direct-progress fallback; no spawn countdown is fabricated.

Chat styling keeps its selected background colour/opacity and adds a matching native metal border. The copy button is larger and separated from the frame.

Validation: full offline runtime/settings/theme suites, installed 0.6.5 public API fixtures, native atlas geometry, click forwarding/restoration, collision reflow and optional gauge constructor. Live visual inspection in the 0.6.5 hero menu and Proving Grounds covered native cards, French meter controls, settings and Elwynn on/off. This is not campaign or co-op acceptance. No native addon, game executable or saved-variable file was edited.
