# 🧭 FieldKit Reborn — World Markers Update

**Version 0.1.0-reborn.35 is now available!**

• Fixed the world-marker engine on Reborn.
• Fixed missing markers on some spawned guardians.
• Improved creature marker placement and chest spacing.
• Added **per-category height controls** for bosses, final bosses, guardians and elites.

Open **`/fieldkit` → World → World markers**, select a category, then adjust:
• **Anchor height** — sets the marker's base position relative to the native overhead point.
• **Extra height** — adds a vertical offset from **0 to 3 metres**.

Changes apply immediately and are saved in your HUD profile. Both native-style and illustrated layouts are supported.

**Already using FieldKit?** Update the addon and restart the game, or use `/reload` if its files were updated while the game was running. Your saved profiles are kept.
