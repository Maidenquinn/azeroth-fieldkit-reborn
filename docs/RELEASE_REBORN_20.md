FieldKit Reborn 0.1.0-reborn.20

The visible target mover is removed. Without a HUD theme, unlock window positions and drag directly on the target health bar, player health bar, minimap or a native spell icon. Each native element has a separate 50–150% size slider in Interface > Layout, and keeps its own position within the current FieldKit HUD profile. Steed follows the moved/scaled spell bar.

Invisible child hit surfaces forward native clicks and tooltips while unlocked and suppress the click after a drag. When locked, native input runs directly. Reward choices disable dragging. Theme handover/logout restores the native geometry; no native addon saved profile or source is edited. Hit surfaces are reused across transitions.

Validation: direct native movement, four scales/anchors, native click context, no click after dragging, lock/choice states, Steed following and repeated release/reacquisition regressions; full offline runtime/theme/settings suite and installed client 0.6.5 API/content fixtures. No new live client pass is claimed.
