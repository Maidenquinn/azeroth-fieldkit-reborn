FieldKit Reborn 0.1.0-reborn.16 — compact first-launch defaults

A truly empty addon database now starts with independent native cards at 85% scale, four character bonuses (damage, haste, critical chance and lifesteal), a separate boss-progress bar and elapsed clock, and one kills/gold/chest/event-currency strip. The redundant standalone Damage taken panel and next-boss footer are off; their information remains available through the meter and progress gauge. Positions start locked, with an independent right column and bottom-centred counters. Chat capture, chat styling and the copy button stay off at first launch. Existing settings are retained.

Interface > Layout now offers Card size without theme. Interface > Profiles > Preview first launch constructs preferences through the actual empty-database initializer each time, using temporary snapshots. Compare Without theme / With theme, then Restore previous. It does not overwrite profile slots or game state; logout restores the original preferences. This is a preference simulation with the same current game data, not a new game/account.

Visual QA exposed stale statistic lines below a newly shortened card and clipped loadout-tab labels. Both are fixed. Unthemed card interiors now use one opacity-controlled fill reaching under the inner native rim, avoiding transparent gaps. A pending mount-state placeholder uses a meaningful mount icon while continuing to mark unavailable charges honestly.

Validation: complete offline runtime suite; 948 registered setting cases across themes; six repeated fresh-default simulations with profile isolation, cancellation and logout restoration; current installed 0.6.5 API/content and all 116 meter-window lengths. Client campaign ready-screen inspection covers first-launch previews and Elwynn on/off. Active combat, a boss encounter and co-op acceptance remain pending: the automation's movement taps did not start the run, and a brief player movement was requested. Do not read this release as a claim that every combat display has passed live QA.
