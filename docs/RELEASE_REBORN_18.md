FieldKit Reborn 0.1.0-reborn.18

Reward choices retain FieldKit's native replacement ownership: the native meter, tracker, resources, jewelry and boss/progress displays no longer return beneath the cards. Temporary native alpha/mouse masks also cover choice transitions and restore prior states afterwards.

Without a theme, unlock window positions and use the handle above the native target frame to move it. Interface > Layout > Native target frame size scales it from 50 to 150%. Placement and scale belong to FieldKit HUD profiles; native event/click handlers and AzerothSurvivorsUI saved settings are preserved. A theme handover restores the original native target geometry.

Independent unthemed cards now allow one physical pixel between outer borders. Reset sits inside the meter footer instead of reserving collision space above it. Themed artwork uses one reference pixel of clearance while retaining the approved edge tolerance.

Validation: full offline runtime/settings/theme suites; new regressions for native reward masking across skins, one-pixel placement at multiple UI scales, internal Reset, native target drag/scale/lock/persistence/restoration; installed client 0.6.5 API/content fixtures. No new live client acceptance is claimed for .18.
