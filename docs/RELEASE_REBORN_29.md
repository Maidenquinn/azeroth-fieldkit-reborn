FieldKit Reborn 0.1.0-reborn.29

The campaign boss card now uses the reference theme artwork: an opaque ornamental rim, the same clean background and body-opacity control as the existing themed cards, and the reference viewport scale. The title, completion count and collapse control have separate header space; boss icons, labels and statuses sit in padded 28-pixel rows. Long labels are fitted without losing the full hover details. The endless notice has its own footer space.

Theme changes restore native styling and icon dimensions. Custom width/height, movement, collapse, profiles and the bounded eight-row pool remain available. Both Elwynn and Naxx families and all variants are covered.

Validation: Automated runtime checks for reference material, header/row bounds, opaque edges and icons at 0/37/100 percent body opacity, viewport scaling, collapse and native restoration, plus the existing campaign/state/locale/settings and installed public API suites. No new live-client visual validation is claimed.
